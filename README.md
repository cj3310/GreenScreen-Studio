# 绿幕抠图工作台 · GreenScreen Studio

基于 Python + PySide6 + OpenCV 的桌面绿幕抠图工具，支持实时预览、参数可调、交互式裁切、批量导出透明 PNG。

## 快速开始

双击 `run.bat` 即可启动（已配置好独立 Python 环境与依赖）。

或手动运行：
```bash
python main.py
```

附赠 `sample_green_screen.mp4` 合成绿幕测试视频，可直接拖入体验。



dist\GreenScreenStudio   目录下有编译好的EXE文件，也可直接使用

## 功能一览

- **拖拽导入**：将 mp4/mov 等视频拖至窗口任意位置即可加载；也支持「打开视频」按钮
- **双画布预览**：左侧原图、右侧抠图，棋盘格底板直观查看透明通道
- **时间轴**：滑块跳帧、方向键逐帧进退、空格播放/暂停，画面自适应窗口缩放
- **交互式裁切**：拖出矩形选框、拖动边框/四角控制点调整、可重置；先裁切再抠图
- **实时抠图参数**：
  - H/S/V 三组上下限独立滑块，精细调节绿色识别范围
  - 吸管取色：点击绿幕自动生成适配 HSV 参数
  - 高斯羽化半径（毛发边缘柔和）
  - 蒙版收缩/扩张（清除边缘残留绿边）
  - 边缘平滑抗锯齿
  - 参数重置、预设保存/加载
  - 蒙版预览开关（单独查看黑白 Alpha 蒙版）
- **批量导出**：自定义输出目录、RGBA 透明 PNG、`frame_000001.png` 命名、可设抽帧间隔、进度条与完成弹窗
- **容错**：非视频文件提醒、视频损坏/路径异常/文件夹创建失败弹窗提示，导出在后台线程运行不卡 UI

## 抠图流程

1. 先按裁切矩形裁剪画面
2. 在裁切区域内做 HSV 色度抠除
3. 蒙版形态学收缩/扩张 + 高斯羽化 + 边缘平滑
4. 合成 RGBA 四通道输出

## 项目结构

```
green-screen-studio/
├── main.py              # 程序入口
├── run.bat               # Windows 启动脚本
├── requirements.txt      # 依赖清单
├── sample_green_screen.mp4   # 测试绿幕视频
└── app/
    ├── keying_engine.py     # 抠图核心算法（HSV/羽化/蒙版/导出）
    ├── canvas_widgets.py    # 棋盘格画布 + 裁切交互 + 吸管取色
    ├── control_panels.py    # 参数面板/时间轴/导出面板
    └── main_window.py      # 主窗口集成
```

## 技术栈

- PySide6 6.11（Qt for Python GUI）
- OpenCV 5.0（视频读取、HSV、形态学）
- NumPy（像素级运算）
- 导出使用 QThread 后台执行，UI 保持响应
